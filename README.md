# Local Media Studio 1.0

Local Media Studio 是一款本地离线影音创作工作台，集成声音克隆、文本配音、图片视频制作、人物口播生成，以及字幕识别、校对与成片导出功能。支持快捷制作和分步操作，帮助你从文案、音频和图片完成视频制作。

## 使用方法

1. 第一次使用时，先运行 `start_workbench.bat`，下载并安装运行所需的环境。
2. 环境准备完成后，双击 `local_media_studio.exe` 启动工作台。
3. 第一次打开工作台时，会先下载并校验所需模型。请等待模型准备完成，随后会自动进入工作台，即可正常使用。
4. 后续使用时，直接双击 `local_media_studio.exe` 即可启动工作台。
