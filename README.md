# Local Media Studio 7.0

This GitHub source package contains the ASCII-layout launcher, Python source, configuration, resources, licenses and model download manifest. Runtime binaries and model weights are intentionally excluded.

Run `local_media_studio.exe` or `start_workbench.bat` on Windows. The first launch installs the bundled runtime if needed, then downloads and verifies all five model groups before opening the workbench.

See `USER_GUIDE.html`, `AGENTS.md`, `program/config/model_download_manifest.json` and `program/config/model_download_sources.json`.
